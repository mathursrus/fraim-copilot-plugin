# FRAIM Workflow Skills for GitHub Copilot

FRAIM is a practical workflow system for using AI coding agents with phased execution, feedback capture, validation evidence, and explicit acceptance criteria.

This plugin gives Copilot users FRAIM-style delivery skills that work directly inside a repository. It does not require a FRAIM account or external service connection to use the bundled skills.

## Included skills

- `fraim`: choose the right FRAIM workflow pattern for the current request.
- `fraim-feature-implementation`: deliver a feature or bug fix through scoping, implementation, validation, and evidence.
- `fraim-address-feedback`: turn review comments, issue rejections, or maintainer feedback into a tracked fix loop.
- `fraim-delivery-evidence`: produce a concise acceptance matrix for marketplace, PR, release, or stakeholder handoff work.

## Optional FRAIM server use

Teams that already use the hosted FRAIM MCP server can connect it separately through their normal Copilot or MCP configuration. The bundled skills remain useful without that setup.
